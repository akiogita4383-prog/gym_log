# REPS（PWA版）セットアップ手順

このフォルダは、ホーム画面に追加して自動保存できる **PWA版のREPS** です。

## 大事な前提
- **自動保存が効くのは https のURLから開いたときだけ** です。
- ファイルをそのままスマホで開いた状態（`file://`）では、ブラウザの仕様で保存できません。
- そのため「どこかに公開 → Safari/Chromeで開く → ホーム画面に追加」という流れになります。

## 中身
```
index.html                アプリ本体
manifest.webmanifest      PWA設定（名前・アイコン・表示）
service-worker.js         オフライン動作（一度開けば圏外でも起動）
icons/                    アプリアイコン（192 / 512 / maskable）
apple-touch-icon.png      iPhoneホーム画面用アイコン
favicon-32.png            タブ用アイコン
```
※ フォルダ構成（`icons/` の位置）は変えないでください。パスがずれると読み込めません。

## 公開する（いずれか1つ）

### A. Netlify Drop（いちばん簡単・登録軽め）
1. https://app.netlify.com/drop を開く
2. この `build` フォルダごとドラッグ＆ドロップ
3. 発行された `https://○○○.netlify.app` を控える

### B. GitHub Pages（無料・URLが安定）
1. GitHubで新規リポジトリを作成
2. `build` の中身（index.html など）をアップロード
3. Settings → Pages → Branch を `main` / `root` にして保存
4. 数十秒後に出る `https://ユーザー名.github.io/リポジトリ名/` を控える

### C. Cloudflare Pages / Vercel
- 同様に静的サイトとしてデプロイすればOK（ビルド設定は不要、そのまま配信）。

## ホーム画面に追加する

### iPhone（Safari）
1. 上で控えた **https のURL** をSafariで開く
2. 下部の「共有」ボタン → **「ホーム画面に追加」**
3. 追加された **REPSアイコン**から起動する

### Android（Chrome）
1. httpsのURLをChromeで開く
2. メニュー（⋮）→ **「アプリをインストール」** または「ホーム画面に追加」
3. 追加されたアイコンから起動する

起動後、記録タブ下の「データ」に **自動保存 ✓** と表示されれば保存が有効です。

## データについて
- 記録はその端末内に保存されます。さらに **クラウド同期（GitHub）** を有効にすると、GitHubの非公開Gistにも自動保存され、端末のデータが消えても・機種変更しても復元できます。
- 機種変更・ブラウザデータ削除に備えて、ときどき「データ」→ **バックアップ書き出し**（JSON）で控えを取り、必要なら「読み込み」で復元してください。

## クラウド同期（GitHub）— おすすめ
端末のデータが消えても記録を守るための自動バックアップです。新しいサービス登録は不要で、既にお持ちのGitHubを使います。

**トークンを作る（1回だけ・約1分）**
1. GitHub → 右上のアイコン → **Settings**
2. 左メニュー最下部 **Developer settings** → **Personal access tokens** → **Tokens (classic)**
3. **Generate new token (classic)** を選ぶ
4. Scopes（権限）は **gist** だけにチェック（他は不要）
5. 作成された `ghp_…` をコピー

**アプリで接続する**
1. REPSの「記録」タブ → 下の **クラウド同期** を開く
2. トークン欄に `ghp_…` を貼り付け → **接続してクラウド保存を開始**
3. 「同期済み ✓」になれば完了。以降は記録するたびに自動でクラウド保存されます。

**別の端末や機種変更後に復元する**
1. 同期中の端末で **Gist IDをコピー**（クラウド同期カードに表示）
2. 新しい端末のREPSで、同じ **トークン** と **Gist ID** を入力 → 接続
3. これまでの記録がすべて復元されます。

**安全性**
- トークンは各端末の中だけに保存され、通信先はGitHubのみです。
- `gist` 権限だけのトークンは、非公開メモ(gist)の読み書き以外はできません。万一漏れても影響は最小で、GitHubの設定からいつでも失効できます。
- 同期は「上書き前に必ずクラウドと突き合わせて統合」する方式なので、複数端末で使ってもデータが消えにくい設計です。

## 動作確認（PCでローカルに試す場合）
`file://` ではService Workerが動かないため、簡易サーバーで開いてください。
```
cd build
python3 -m http.server 8000
```
ブラウザで `http://localhost:8000` を開くと、保存・PWA動作を確認できます。
